# Task Manager Project (Console Version)

## 📌 Description
A simple console-based Task Management System that allows users to add, view, update, delete, filter, sort, and search tasks.  
This project is built using Java and demonstrates CRUD operations and basic console interaction.

## 📌 Features
- Add Task  
- View Tasks  
- Update Task  
- Delete Task  
- Filter Tasks (by status or priority)  
- Sort Tasks (by due date)  
- Search Tasks (by title or description)

## 📌 How to Run
1. Clone the repository:
   git clone https://github.com/Bayan-IT/TaskManagementProject

2. Open the project in VS Code or IntelliJ.

3. Run `Main.java`.

4. Use the menu to interact with the task manager.
